# NailCheck

Vídeos con IA para NailCheck (pegatinas de uña detectoras de bebidas adulteradas). Misma forma de trabajar que `BackAlign/`.

```
aprendizajes/        ← LEER ANTES DE GENERAR
  lecciones.md
  prompts-que-funcionan.md
  registro-generaciones.md
productos/           ← fotos de referencia del producto (limpias, <color>_<vista>.png)
avatares/            ← caras de los avatares de IA
proyectos/           ← un vídeo = una carpeta: AAAA-MM-DD_persona_nombre
    referencia/  trozos/  generaciones/  final/
```

Las descargas y transcripciones automáticas usan `BackAlign/sistema/` (compartido).
