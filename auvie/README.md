# Auvie — collares personalizados

Proyecto de vídeos de collares (nombre personalizado, colgante). Misma forma de trabajo que el resto del repo (ver `aprendizajes/`).

```
videos-collares/   ← vídeos de referencia de collares
avatares/          ← avatares de IA para estos vídeos
```

## Avatares
- `avatar-rubia-frente.png` — rubia joven, pelo largo ondulado, ojos claros, boca cerrada, top blanco acanalado, cuello despejado (sin collar). Creada con gpt-image-2 a partir de `referencia-rubia.png` (0,015 $).
- `avatar-rubia-solo-cara.png` — recorte de cabeza y cuello.
