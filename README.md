# Referencias y vídeos con IA

Tres proyectos distintos que crean vídeos con IA:

- **`BackAlign/`** — sujetador corrector de postura. Todo el sistema de trabajo (aprendizajes, avatares, productos, proyectos y descargas automáticas) está dentro; empieza por `BackAlign/README.md`.
- **`NailCheck/`** — pegatinas de uña detectoras de bebidas adulteradas.
- **`Snowbox/`** — calendarios, planners y juegos de Navidad imprimibles. Sus `aprendizajes/` ya incluyen las lecciones comunes a todos los proyectos.
